## Figma AI Prompt

> **Project:** Medical Appointment Booking Web App — Full UI Kit & Screen Set
> **Stack:** React + Tailwind CSS
> **Modes:** Light & Dark | **Languages:** English (LTR) + Arabic (RTL)
> >
> ---
> >
> ### 🎨 Design System
> >
> Create a cohesive design system with a professional medical feel. Choose a color palette that feels trustworthy and modern — think deep blues, teals, or similar medical-grade tones with a complementary accent color. Define typography, spacing, shadow, and border radius tokens. Build a full component library including buttons, inputs, dropdowns, modals, cards, badges, avatars, tooltips, sidebar navigation, navbar, breadcrumbs, and pagination. Include appointment status badges for: Pending, Confirmed, Completed, and Cancelled — each with a distinct color.
> >
> ---
> >
> ### 👤 Three Portals
> >
> **Patient Portal:**
> - Landing page (hero, features, top doctors, CTA)
> - Register & Login pages
> - Doctor listing with search and filters
> - Doctor profile with bio and availability calendar
> - Appointment booking flow (date → time → confirm)
> - My Appointments page (Upcoming / Past / Cancelled tabs)
> - Patient profile / edit profile
> >
> **Doctor Portal:**
> - Dashboard with stats and today's schedule
> - Weekly availability manager
> - Appointments list with approve / reject / notes actions
> - Doctor profile edit page
> >
> **Admin Portal:**
> - Dashboard with key stats and charts
> - Users management table (approve / block)
> - Specialties management (CRUD)
> - All appointments filterable table
> >
> ---
> >
> ### 🌗 Dark & Light Mode
> >
> Every screen needs both a Light and Dark variant. Use Figma variables to handle the switch. Dark mode should feel deep and refined — avoid pure black backgrounds.
> >
> ---
> >
> ### 🌐 RTL / Arabic Support
> >
> Every screen needs an Arabic RTL variant placed beside its LTR version. Mirror the layout horizontally — sidebar flips sides, text aligns right, directional icons flip. Use Cairo or Noto Sans Arabic for Arabic text. Fill screens with realistic Arabic placeholder content.
> >
> ---
> >
> ### 📐 Responsive Breakpoints
> >
> Design primarily for Desktop (1440px). Add Tablet (768px) and Mobile (375px) variants for the Patient Portal screens. On mobile, the sidebar becomes a bottom nav bar or hamburger drawer.
> >
> ---
> >
> ### ✨ Style Direction
> >
> Clean, modern, and trustworthy — like a premium healthcare SaaS product. Use card elevation and subtle depth for visual hierarchy. Avoid childish illustrations. Populate every screen with realistic dummy data — real-looking doctor names, specialties, dates, and times. Use a consistent outline icon set throughout. Let the overall aesthetic, layout choices, and visual style be your creative decision.
